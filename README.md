# Streamline Checklist Notepad & Admin Dashboard

An advanced, feature-rich web notepad and checklist application equipped with an encrypted owner control panel, live visitor tracking, Roblox-style administration commands, and a customizable timed announcement broadcaster.

## 🌐 Live Website
Access the live application here:
[https://zeroid-san.github.io/ONLINE-NOTE-APP/](https://zeroid-san.github.io/ONLINE-NOTE-APP/)

---

## ✨ Features

### 📝 Core Notepad & Checklist
* **Text-to-Checklist Conversion**: Instantly parse multi-line text blocks into clean, interactive checklist elements.
* **Drag-and-Drop File Support**: Drag and drop text, code, config files (`.txt`, `.json`, `.csv`, `.js`, `.html`, etc.) directly into the workspace to convert contents into checklist tasks.
* **Interactive Drag-and-Drop Reordering**: Rearrange checklist items effortlessly using native drag-and-drop handles.
* **Dynamic Prefix Styles**: Customize item prefixes with Numbers (`1, 2, 3`), Bullets (`•`), Letters (`a, b, c`), or None.
* **Context Menus**: Inline item options to quickly edit or delete individual checklist items.

### 🔒 Owner Secret & Admin Panel
* **Secure Authentication**: Protected owner modal accessed via the bottom-left corner trigger, keyboard shortcut (`Ctrl + 0`), or emergency bypass prompts.
* **Roblox-Style Admin Commands**:
  * `:shutdown` — Lock down the entire website into a maintenance screen for other users.
  * `:open` — Restore full public access instantly.
  * `:clearstorage` — Wipe and reset user storage data remotely.
* **Timed Announcement Broadcaster**: Push customizable banner announcements globally across all active visitor sessions with configurable message text, background color pickers, and active duration timers.
* **Live Visitor Analytics**:
  * **Active Visitors List**: Real-time display of currently online visitor IP addresses and geographic locations.
  * **Left Visitors Tracker**: Session history log showing visitors who disconnected alongside their departure timestamps.
  * **Traffic Trend Graph**: Visual 5-day traffic distribution graph.
