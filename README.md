## ⚡ Features

- **Duplicate Prevention Engine:** Automatically filters out and rejects identical text lines/character blocks on input to keep your lists clean.
- **Universal File Drag & Drop:** Drop any file format directly into the workspace. Text-based files (`.txt`, `.json`, `.csv`, code scripts, etc.) automatically parse into line items, while binary files or media register file metadata.
- **Dynamic Formatting & Prefixes:** Customize your list structure instantly via the persistent Settings menu with options for **Numbers**, **Bullets**, **Letters**, or **None**.
- **Interactive Checklist Management:** Reorder items seamlessly via drag-and-drop handles, check items off with persistence tracking, and edit or delete entries on the fly.
- **Local-First Storage:** All checklist items, states, and user configuration preferences are securely saved locally via `localStorage`.
